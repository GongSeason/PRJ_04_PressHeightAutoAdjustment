# PLC Communication Integration Plan

## Objective
Replace MockPlcAdapter with a real PLC adapter using HslCommunication.dll (KeyenceMcNet) for Keyence PLC communication via MC Qna 3E Binary protocol over TCP. Add capability to read head positions from PLC registers.

## Current Architecture
- **IPlcAdapter interface**: `SendAdjustmentAsync(int headIndex, double deltaMm)`, `SendStopAsync(string reason)`
- **MockPlcAdapter**: Logs to console, no real communication
- **MainViewModel.RefreshDataAsync()**: Calls `_plcAdapter.SendAdjustmentAsync()` / `SendStopAsync()` on timer tick (every 10-30 seconds)
- **AppSettings**: Configuration for monitor path, scan days, refresh interval, controller parameters
- **MainWindow.xaml**: Settings panel with UI bindings
- **PLC Communication**: No real PLC communication exists, only mock adapter

## Implementation Steps

### Step 1: Add PlcSettings Model
**File**: `CrimpHeightAnalyzer/Models/AppSettings.cs`

Add nested configuration class:

public class PlcSettings
{
    public string IpAddress { get; set; } = "192.168.1.10";

### Step 3: Extend IPlcAdapter Interface
**File**: `CrimpHeight.Core/Interfaces/IPlcAdapter.cs`

Add read method to interface:

/// <summary>
/// 读取压头当前位置
/// </summary>

### Step 4: Create KeyencePlcAdapter
**New file**: `CrimpHeightAnalyzer/Services/KeyencePlcAdapter.cs`

Key features:
- Implements `IPlcAdapter` and `IDisposable`
- Uses `KeyenceMcNet` from HslCommunication.Profinet.Keyence
- Async operations with `SemaphoreSlim` for thread safety
- Connection status events for UI feedback
- Lazy reconnect on failure
- Configurable register addresses
- **Read head position from PLC registers**

### Step 5: Update MockPlcAdapter
**File**: `CrimpHeightAnalyzer/Services/MockPlcAdapter.cs`

Add implementation for new `ReadHeadPositionAsync` method:

## Risks & Considerations
- **DLL API**: Verify KeyenceMcNet class exists in HslCommunication.dll (not in Keyence_TCP_use_protocol_MC_Qna_3E_binary.dll)
- **Register format**: Confirm address format (e.g., "D100" vs "D100.0")
- **Thread safety**: SemaphoreSlim needed for concurrent PLC writes
- **Mock mode preserved**: UseRealPlc flag allows easy switching for development
- **Read data format**: Verify PLC returns float (32-bit) for position data
- **Address mapping**: Confirm D300/D302 are correct for head positions
