## 1. 系统概述

### 1.1 它做什么

系统实时读取压接机的 CSV 数据，对**两个压头**分别执行：

1. **统计分析** — 截尾均值、标准差、发散检测
2. **决策仲裁** — 五级优先级判断，每拍产出唯一结论
3. **调整建议** — 计算压头该升/降多少，发送给 PLC

### 1.2 两个压头的分工

| 压头 | 负责产品 | 说明 |
|------|---------|------|
| 压头A | 产品3 + 产品4 | 一次压两个产品 |
| 压头B | 产品1 + 产品2 | 一次压两个产品 |

### 1.3 控制范式

**R2R（Run-to-Run）**：每个压接周期结束后，根据统计结果决定下一周期的压头位置。不是实时连续控制，而是"跑完一轮→算→调→再跑"。

## 3. 核心算法

### 3.1 截尾均值

排序后去掉头尾各 `TrimPercentage` 比例的数据，对剩余部分求平均。

**目的：** 消除偶发极端值对均值的影响。

```
原始数据: [12.58, 12.59, 12.60, 12.61, 12.90]  ← 12.90 是异常值
排序后:   [12.58, 12.59, 12.60, 12.61, 12.90]
截尾 5%:  去掉最高 1 个 → [12.58, 12.59, 12.60, 12.61]
均值:     12.595  ← 不受 12.90 影响
```

### 3.2 R2R 控制律

```
偏差 Deviation = 截尾均值 − 目标点(规格中点)
调整量 Δ = K × Deviation
```

- **K = 0.5** → 每次修正偏差的 50%，需要多轮收敛
- **死区** — 偏差在 ±容差范围内时 Δ = 0（不调整）
- **步长限幅** — |Δ| 不能超过 MaxStepPerAdjust

**示例：**
```
规格: 12.55 ~ 12.65，目标 = 12.60
当前截尾均值 = 12.623
Deviation = 12.623 − 12.60 = +0.023（偏高）
K = 0.5
Δ = 0.5 × 0.023 = +0.0115mm
限幅后 Δ = +0.01mm（受 MaxStepPerAdjust 限制）
→ 压头下降 0.01mm（压深一点，降低高度）
```

### 3.3 发散检测

两个产品共用一个压头，但各自有独立的截尾均值。如果两个产品差异过大，说明工位有问题。

```
D = 产品1截尾均值 − 产品2截尾均值
```

| |D| 范围 | 等级 | 行为 |
|---------|------|------|
| < T | Normal | 正常控制 |
| T ~ 2T | Degraded | 继续控制，但 K 减半（更保守） |
| > 2T | Stop | 停机报警，单靠调压头无法兼顾 |

### 3.4 漂移检测

判断数据是否有持续单方向偏移的趋势。

**v1 判据：** 连续 N 拍（默认 3）的线性回归斜率同号（全正或全负）。

- 全正 → 持续上升趋势 → Drift
- 全负 → 持续下降趋势 → Drift
- 有正有负 → 噪声，不是漂移

### 3.5 安全护栏

三层兜底检查，任一触发即判 Outlier：

| 检查项 | 触发条件 | 说明 |
|--------|---------|------|
| 合理性阈 | 均值超出 [SafetyLowerBound, SafetyUpperBound] | 正常生产不可能到的范围 |
| σ 突增 | 当前标准差 > 基线标准差 × SigmaSpikeFactor | 离散度突然变大 |
| 数据失活 | 超过 DataStaleTimeoutSeconds 没有新数据 | 设备可能停了 |

## 4. 参数指南

### 4.1 总览

共 **15 个参数**，按来源分四类：

| 来源 | 参数 | 个数 |
|------|------|------|
| 图纸/工艺文件 | UpperLimit, LowerLimit, UpperTolerance, LowerTolerance | 4 |
| 设备特性 + 实测 | ControllerGain, MaxStepPerAdjust, WindowSize, DivergenceThreshold | 4 |
| 统计惯例 | TrimPercentage, MinSamplesPerEpoch, DegradedGainFactor, DriftConfirmCycles | 3 |
| 兜底防护 | SafetyUpperBound, SafetyLowerBound, SigmaSpikeFactor, DataStaleTimeoutSeconds | 4 |

### 4.2 规格参数

#### UpperLimit — 压接高度上限 (mm)

- **是什么：** 图纸标注的规格上限
- **怎么填：** 直接抄图纸。例：12.55~12.65mm → 填 **12.65**
- **影响：** TargetMidpoint = (UpperLimit + LowerLimit) / 2，即控制目标点

#### LowerLimit — 压接高度下限 (mm)

- **是什么：** 图纸标注的规格下限
- **怎么填：** 直接抄图纸。例：填 **12.55**

#### UpperTolerance — 死区上限 (mm)

- **是什么：** 偏差向上超过这个值才触发调整。不是规格限！
- **怎么填：** = 规格公差的 20%~40%。公差 0.10mm → 填 **0.02~0.04**
- **为什么不能等于规格限：** 如果死区 = 规格范围，系统要等到快超差才调整，来不及

#### LowerTolerance — 死区下限 (mm)

- **是什么：** 偏差向下超过这个值才触发调整
- **怎么填：** 一般和 UpperTolerance 对称，填一样的值

### 4.3 控制律参数

#### ControllerGain (K) — 控制器增益

- **是什么：** 每次修正吃掉多大比例的偏差
- **怎么填：** 从 0.3 开始，观察收敛速度，逐步加大
- **参考：**

| K 值 | 效果 | 适用场景 |
|------|------|---------|
| 0.3 | 收敛慢，但稳定 | 噪声大、怕振荡 |
| 0.5 | 平衡点（推荐起步值） | 多数场景 |
| 0.7 | 收敛快 | 数据干净、漂移快 |

- **怎么标定：** 让压头故意偏一个已知量（如 0.03mm），观察几拍后回到死区的速度。3~5 拍收敛 → K 合适；来回振荡超过 2 轮 → K 太大

#### MaxStepPerAdjust — 单步最大调整量 (mm)

- **是什么：** 单次调整量上限，防止一拍调太多
- **怎么填：** = 压头的机械最小步进。如果最小步进 0.01mm → 填 **0.01**
- **设太小：** 等于不调整
- **设太大：** 可能跳过最佳位置

### 4.4 统计参数

#### TrimPercentage — 截尾比例

- **是什么：** 去掉头尾各多少百分比的极端值
- **怎么填：** 固定填 **0.05**（5%）。噪声特别大可调到 0.10
- **示例：** 200 条数据，5% = 去掉头尾各 10 条

#### WindowSize — 分析窗口大小

- **是什么：** 用最近多少条数据来计算统计量
- **怎么填：** 由采样率和漂移速度共同决定

| 采样率 | WindowSize=200 覆盖时长 | 适用 |
|--------|------------------------|------|
| 1 pts/s | 200 秒 ≈ 3.3 分钟 | 漂移慢的工艺 |
| 10 pts/s | 20 秒 | 漂移快 / 需要快速响应 |
| 100 pts/s | 2 秒 | 可能太短，需加大窗口 |

- **起步建议：** 先用 200，跑一轮看响应。如果系统对漂移反应太慢 → 缩小；如果统计量波动太大 → 加大

#### MinSamplesPerEpoch — 最少样本数

- **是什么：** 数据少于这个值时，不信任统计结果，判 WarmUp
- **怎么填：** = WindowSize × 25%~30%。窗口 200 → 填 **50**
- **什么时候触发：** 刚开机、换模、epoch 重置后，数据还不够的时候

### 4.5 发散参数

#### DivergenceThreshold (T) — 发散阈值 (mm)

- **是什么：** 两产品截尾均值之差 D 的容忍上限
- **怎么填：** = 规格公差的 20%~50%。公差 0.10mm → 填 **0.02~0.05**
- **D 和偏差的区别：**

```
Deviation = (P1+P2 合并均值) − 目标    → 整体偏不偏
D = P1 均值 − P2 均值                   → 两工位一致不一致

可能 Deviation≈0 但 D 很大 → 均值刚好在目标上，但两个工位差很多
这种情况下单调压头没用，要查工位
```

#### DegradedGainFactor — 降级 K 折减系数

- **是什么：** 进入 Degraded 区后 K 打几折
- **怎么填：** 固定填 **0.5**（减半）。PRD 建议值，不需要调

#### DriftConfirmCycles (N) — 漂移确认拍数

- **是什么：** 连续几拍同方向趋势才确认漂移
- **怎么填：**

| N | 效果 |
|---|------|
| 2 | 反应快，但容易误报（噪声触发） |
| 3 | 推荐起步值 |
| 5 | 更保守，抗噪强，但反应慢 |

### 4.6 安全护栏参数

#### SafetyUpperBound — 合理性上限 (mm)

- **是什么：** 均值超过这个值一定是出了大问题（传感器故障、换错料等）
- **怎么填：** = 规格上限 + 0.15~0.20mm。规格 12.65 → 填 **12.80**

#### SafetyLowerBound — 合理性下限 (mm)

- **是什么：** 同上，向下
- **怎么填：** = 规格下限 − 0.15~0.20mm。规格 12.55 → 填 **12.40**

#### SigmaSpikeFactor — σ 突增倍数

- **是什么：** 标准差突然增大多少倍，判过程失控
- **怎么填：** 3.0 起步。如果误触发（正常生产时偶尔报警）→ 加到 4.0

#### DataStaleTimeoutSeconds — 数据失活超时 (秒)

- **是什么：** 多久没收到新数据就判设备异常
- **怎么填：** = 设备正常出数间隔 × 3~5。正常 2 秒一条 → 填 **30~60**

## 5. 状态机与仲裁逻辑

### 5.1 六状态总览

| 状态 | 含义 | UI 显示 | PLC 调整量颜色 | 系统行为 |
|------|------|---------|---------------|---------|
| **WarmUp** | 数据不够，统计不可信 | ⏳ WarmUp | 灰色 | 不动作，显示"采集中" |
| **Stable** | 偏差在死区内，无漂移 | ✓ Stable | 绿色 | 不动作 |
| **Drift** | 偏差越界或确认漂移 | ↗ Drift | 黄色 | 计算 Δ，发送 PLC |
| **Drift (Degraded)** | 偏差越界或确认漂移，且产品间有落差 | ⚠ Drift (Degraded) | 黄色 | 计算 Δ（K减半），发送 PLC |
| **Diverged** | 产品间发散严重 | ⛔ Diverged | 红色 | 停机报警 |
| **Outlier** | 安全护栏触发 | 🚨 Outlier | 红色 | 停机报警 |

### 5.2 状态触发条件详解

#### **Outlier**（优先级 1 — 最高）

安全护栏触发，任一条件满足即进入：

| 检查项 | 触发条件 | 说明 |
|--------|---------|------|
| 合理性阈 | 均值超出 [SafetyLowerBound, SafetyUpperBound] | 正常生产不可能到的范围 |
| σ 突增 | 当前标准差 > 基线标准差 × SigmaSpikeFactor | 离散度突然变大 |
| 数据失活 | 超过 DataStaleTimeoutSeconds 没有新数据 | 设备可能停了 |

```
触发 → 停机报警，不计算调整量
```

#### **WarmUp**（优先级 2）

置信不足：
- 有效样本数 < MinSamplesPerEpoch（默认50）

```
触发 → 采集中，不动作
```

#### **Diverged**（优先级 3 — 发散停止）

产品间发散严重：
- |产品1截尾均值 - 产品2截尾均值| > 2 × DivergenceThreshold

```
触发 → 需维护，已停机（红色）
```

#### **Drift**（优先级 4）

偏差越界 **或** 漂移确认：

**条件 1 — 偏差越界：**
- |截尾均值 - 目标中点| > 容差（UpperTolerance / LowerTolerance）

**条件 2 — 漂移确认（双条件）：**
- 方向一致：连续 N 拍 slope 同号（全正或全负）
- 幅度显著：最近 N 拍平均 |slope| ≥ DriftSlopeThreshold

**发散等级细分：**

| 发散等级 | 条件 | 显示 | K 值 |
|---------|------|------|------|
| Normal | |D| < T | Drift — 漂移 | 全速 K |
| Degraded | T ≤ |D| ≤ 2T | Drift (Degraded) | K × 0.5 |

```
触发 → 计算调整量，发送PLC
```

#### **Stable**（优先级 5 — 最低）

以上条件均不满足：
- 偏差在容差内
- 无确认漂移
- 发散正常

```
触发 → 无需调整（绿色）
```

### 5.3 五级仲裁流程（命中即止）

每拍每压头按以下顺序检查，**命中即停**，只产出一个结论：

```
优先级 1 → 安全护栏触发？           → Outlier        + 停机报警
优先级 2 → 样本 < MinSamples？       → WarmUp         + 不动作
优先级 3 → |D| > 2T？                → Diverged       + 停机报警
优先级 4 → 越界 或 漂移确认？        → Drift          + 调整（黄色）
优先级 5 → 以上都没有                → Stable         + 不动作（绿色）
```

### 5.4 发散三级

| |D| 范围 | 等级 | 动作 |
|---------|------|------|
| < T | Normal | 正常控制，全速 K |
| T ~ 2T | Degraded | 继续控制，K × 0.5（保守） |
| > 2T | Stop | 停机，调压头解决不了 |

### 5.5 典型场景

**场景 A：正常生产**
```
截尾均值 = 12.601，偏差 = +0.001mm
容差 = ±0.02mm → 在死区内
D = 0.003，< T
→ Stable，不动作 ✓（绿色）
```

**场景 B：缓慢漂移**
```
连续 3 拍：均值 12.621 → 12.624 → 12.628
偏差超过容差 +0.02
DriftScore: 3 拍斜率全正，平均|slope| ≥ 门限 → 确认漂移
D = 0.005，Normal
→ Drift，Δ = 0.5 × 0.028 = +0.014mm → 限幅到 +0.01mm
→ 压头下降 0.01mm（压深一点，降低高度）（黄色）
```

**场景 C：漂移 + 产品间落差**
```
偏差超过容差，确认漂移
D = 0.015，T = 0.02 → Degraded
→ Drift (Degraded)，K 减半，更保守调整（黄色）
```

**场景 D：两工位不一致**
```
产品3 均值 = 12.63，产品4 均值 = 12.57
D = 0.06，T = 0.02
|D| = 0.06 > 2T = 0.04 → Stop
→ Diverged，停机报警，需检查工位（红色）
```

**场景 E：刚开机**
```
只有 20 条数据，MinSamples = 50
→ WarmUp，不动作，UI 显示"采集中"（灰色）
等数据积累到 50 条后才进入 Stable 或 Drift
```

**场景 F：传感器故障**
```
均值 = 12.85，超出 SafetyUpperBound = 12.80
→ Outlier，停机报警（红色）
```

## 6. 操作指南

### 6.1 首次使用

1. 打开应用，点击右上角 **设置**
2. 填写 **监视路径**（CSV 文件所在目录）
3. 填写 **规格参数**（UpperLimit、LowerLimit，抄图纸）
4. 填写 **容差**（UpperTolerance、LowerTolerance，建议 0.02）
5. 其他参数先用默认值
6. 点击 **保存设置**
7. 观察趋势图和状态指示，确认数据读取正常

### 6.2 调参流程

```
第 1 轮：默认参数跑一轮，观察
  ↓
状态一直 Stable 但实际有漂移？ → 降低 UpperTolerance/LowerTolerance
  ↓
频繁报 Drift 但实际没漂移？ → 加大 DriftConfirmCycles（3→5）
  ↓
收敛太慢（好几轮才回到目标）？ → 加大 ControllerGain（0.5→0.7）
  ↓
收敛振荡（来回调）？ → 降低 ControllerGain（0.5→0.3）
  ↓
Degraded 频繁出现？ → 加大 DivergenceThreshold（0.02→0.03）
  或检查两个工位的机械一致性
```

### 6.3 界面说明

| 区域 | 内容 |
|------|------|
| 顶部标题栏 | 系统名称、状态文本、刷新/设置按钮 |
| 压头A/B 卡片 | 状态标签、PLC调整量（大字醒目）、偏差、Slope、截尾均值 |
| 告警区域 | 仅在 Outlier 或 Diverged 时显示 |
| 调整参数卡 | 当前的规格限、目标、容差一览 |
| 趋势图 | 四产品实时趋势线 + 上下限参考线 |
| 设置面板 | 所有可调参数 |

### 6.4 压头卡片布局

```
┌─────────────────────────────────┐
│ 压头A                    Stable  │  ← 标题 + 状态标签（颜色）
```

## 7. 常见问题

### Q: 状态一直显示 WarmUp 不动？

**原因：** 有效数据量 < MinSamplesPerEpoch（默认 50）
**解决：** 等待数据积累。如果 CSV 文件数据量本身就不足，调小 MinSamplesPerEpoch

### Q: 一直报 Outlier？

**原因：** 安全护栏触发。检查：
1. 均值是否真的超出 SafetyUpperBound/LowerBound → 调大范围
2. 标准差是否突增 → 检查设备是否异常
3. 数据是否长时间没更新 → 检查文件路径和设备连接

### Q: 两个压头状态不一样？

**正常。** 两个压头独立分析，互不影响。压头A 看产品3+4，压头B 看产品1+2。

### Q: Diverged 和 Outlier 有什么区别？

| | Diverged | Outlier |
|---|---|---|
| 触发原因 | 两产品差异过大（\|D\| > 2T） | 安全护栏触发 |
| 含义 | 工位不一致，调压头没用 | 数据本身有问题 |
| 处理 | 检查两个工位的机械状态 | 检查传感器/物料/数据源 |

### Q: Drift 和 Drift (Degraded) 有什么区别？

| | Drift | Drift (Degraded) |
|---|---|---|
| 发散等级 | Normal（\|D\| < T） | Degraded（T ≤ \|D\| ≤ 2T） |
| K 值 | 全速 K | K × 0.5（更保守） |
| 含义 | 正常漂移调整 | 漂移调整 + 产品间有落差 |

### Q: Slope 门限怎么设置？

Slope 门限用于过滤噪声，避免微小波动触发漂移报警。

| 门限值 | 效果 | 适用场景 |
|--------|------|---------|
| 0.00001 | 容易触发（敏感） | 漂移很慢，需要早期发现 |
| 0.0001 | 平衡（默认） | 多数场景 |
| 0.001 | 不容易触发（保守） | 噪声大，只报明显漂移 |

**建议：** 先用默认值 0.0001，观察界面显示的 Slope 值，根据实际情况调整。

### Q: 窗口大小设多少合适？

看你的**采样率**和**漂移速度**：
- 采样率 10pts/s，窗口 200 → 覆盖 20 秒
- 采样率 1pts/s，窗口 200 → 覆盖 200 秒 ≈ 3 分钟

原则：窗口要覆盖至少 **1~2 个漂移周期**。如果不确定，先用 200。

### Q: 我只想看分析结果，不想让系统自动调整怎么办？

当前版本使用 MockPlcAdapter（日志输出），不会实际控制 PLC。调整建议只在 UI 上显示和写入日志。接入真实 PLC 时需要替换为实际的 PlcAdapter 实现。
